# Toma’s Birthday Boots

A playful, customizable birthday website with illustrated cowboy boots and an animated birthday finale.

Open `index.html` in a browser. No installation or build step is required.

## Publish with GitHub Pages

Upload `index.html` and `.nojekyll` to the repository’s main branch. In the repository’s Settings → Pages, choose “Deploy from a branch”, select `main` and `/ (root)`, and save.

Fonts load from Google Fonts; system fonts are used when unavailable.
